These are the .asc, .btl, and .hdr files from subfolder process_ctd_data_for_Heidi, received on 2022-02-22 the day after cruise AT46.
These are "as is" as we walked off the ship, with processing by Lynne Butler.
Note that the oxygen sensor was swapped between cast 18 and cast 19.
Note that the following sensors had not been calibrated for more than 3 years: PAR sensor, SPAR sensor, combo fluorometer/turbidity, CStar.
